# 라이어 게임 (오프라인 · 폰 하나)

폰 한 대를 돌려가며 하는 라이어(임포스터) 게임. 빌드 없는 정적 사이트라 GitHub Pages에 그대로 올리면 된다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 진입점 |
| `style.css` | 테마 (흰 배경·#222 텍스트·#ee4132 포인트, 다크 모드 지원) |
| `app.js` | 화면 전환·게임 로직 (바닐라 JS) |
| `words.js` | 제시어 단어쌍 16개 주제 × 30쌍 (중학생 교실 기준) + 그리기 모드용 단어 10개 주제 × 25개 |
| `.nojekyll` | GitHub Pages가 Jekyll 처리를 건너뛰게 함 |

## 로컬 실행

```bash
python -m http.server 8765
```

브라우저에서 http://localhost:8765 을 연다.

## GitHub Pages 배포

1. 이 폴더를 저장소 루트로 push 한다 (`.claude/` 는 올리지 않아도 된다).
2. 저장소 Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `(root)`.

## 게임 흐름

설정 → 제시어 확인(카드 탭 → 확인 → 다음 사람) → 설명·토론(타이머) 또는 이어 그리기 → 투표(동시 지목 또는 비밀 투표, 동점 시 재투표) → 정체 공개 → 라이어의 마지막 기회 → 결과·누적 점수.

- 게임 방식: 말로 설명 / 그리기(설명 대신 폰을 돌려가며 한 사람씩 한 획만 이어 그림, 플레이어별 색, 1~3바퀴)
- 라이어 팀: 자리마다 역할을 따로 고른다. 라이어(주제만 앎) / 바보(모른 채 비슷한 다른 단어를 받음, 그리기에서는 같은 주제의 다른 단어) / 스파이(제시어와 라이어 팀을 알고 돕는다, 지목돼도 오지목). 라이어나 바보가 최소 1명.
- 라이어 팀 자리 수: 3~4명 1, 5~6명 2, 7~8명 3, 9명 이상 4
- 점수: 시민 승리 시민 +1, 오지목·재투표 동점 라이어 팀 +3, 라이어 역전(제시어 맞힘) 라이어 팀 +2
- 설정·이름·누적 점수는 브라우저 `localStorage` 에 저장된다.

## 제시어 추가

그리기 모드 단어는 `DRAW_WORDS` 의 `words` 에 하나씩 넣는다 (선 몇 개로 알아볼 수 있는 사물만). 일반 모드는 `words.js` 의 `pairs` 에 `['단어 A', '단어 B']` 를 넣는다. 라운드마다 둘 중 하나가 시민 단어, 나머지가 바보가 받는 단어가 된다. 같은 주제 안에서 비슷하지만 설명하면 차이가 드러나는 구체적 명사가 좋다.
